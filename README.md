# Shortest Othello

## ビルド&実行方法

### Linux

```bash
gcc -c main.c -w
gcc -o othello.exe main.o
./othello.exe
```

### Windows

run.batを使用してください。

## 操作方法

ターンごとに`Y X`の順で石を置く場所を入力してください。
